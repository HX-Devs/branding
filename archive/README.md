# Archived brand explorations

These files preserve the development of the Helix identity. They are historical references and may contain superseded geometry, type, colors, proportions, or motion.

- `original-symbol/`: the original symbol and horizontal lockups.
- `explorations/monograms/`: initial separate HX and HLX lettering.
- `explorations/ligatures/`: shared-stroke explorations, variants, and refinement previews.
- `explorations/palettes/` and `explorations/palette-comparison.svg`: alternative palette studies.
- `animation/`: earlier SVG animation, static frames, previous CSS, and sampled motion data.

For current production assets, use [logos](../logos/), [guidelines](../guidelines/), [social assets](../social/), and [CSS motion](../animation/README.md).
